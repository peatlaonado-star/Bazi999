# STARVIA Thai Astrology Product Roadmap

> **Product direction:** STARVIA should become a modern Thai life-map system — not a generic fortune-telling site. It keeps Thai astrological roots while presenting them with premium UX, practical guidance, and language that feels meaningful to modern users.

## 1. Positioning

**One-line positioning**

> ระบบอ่านแผนที่ชีวิตด้วยโหราศาสตร์ไทย สำหรับคนยุคใหม่

**Brand promise**

> ดวงดาวไม่ได้บังคับชีวิตคุณ แต่ช่วยให้เห็นจังหวะที่ควรก้าว จุดที่ควรระวัง และวิธีปรับชีวิตให้มั่นคงขึ้น

**Core principles**

1. **ไทยแท้ แต่ไม่เชย** — use Thai astrology concepts, not generic zodiac-only content.
2. **ลึก แต่ไม่ขู่** — avoid fear-based language; focus on self-awareness and practical choices.
3. **เฉพาะตัว** — every result should feel generated from the user's birth profile, not pasted from a daily horoscope.
4. **ทำต่อได้จริง** — every reading should include practical rituals/actions.
5. **พรีเมียมและแชร์ได้** — visual cards should look like a premium Thai cosmic brand, not a cheap fortune site.

STARVIA should prioritize these Thai-rooted systems:

| Pillar | Purpose in Product | User-facing framing |
|---|---|---|
| วันเกิด 7 วัน | base personality and daily energy | ดาวประจำตัว / พลังวันเกิด |
| ดาวนพเคราะห์ | archetypes and life lessons | ดาวเจ้าชะตา / ดาวบทเรียน |
| ธาตุ | emotional/behavioral operating system | ธาตุชีวิต |
| ทักษาปกรณ์ | strengths and shadow patterns | พรสวรรค์หนุนดวง / เงาในใจ |
| ลัคนา | deeper identity and direction | ประตูชีวิต / ตัวตนเบื้องลึก |
| ราศีไทย | expression style | วิธีแสดงพลังบนโลก |
| ฤกษ์ยาม | timing guidance | จังหวะลงมือเฉพาะบุคคล |

**Tone conversion rule**

Old-style wording:

> ดาวเสาร์เป็นกาลกิณีแก่เจ้าชะตา

STARVIA wording:

> ชีวิตมักทดสอบคุณผ่านความกดดัน ความล่าช้า และความรับผิดชอบหนัก แต่ถ้าฝึกวินัยได้ ดาวเสาร์จะเปลี่ยนจากแรงกดเป็นพลังสร้างฐานะ

## 3. Product Modules

### Module A: Thai Life Blueprint

**Goal:** Turn basic birth data into a premium personal life map.

**Inputs**
- Name
- Gender / identity label
- Birth date
- Birth time
- Optional: province/country later for more accurate timezone/luxury version

**Outputs**
- ดาวประจำตัว
- ธาตุชีวิต
- ราศีเกิด
- ลัคนา
- จุดแข็งหลัก
- เงาในใจ / บทเรียนซ้ำ
- วิธีปรับฐานชีวิต
- mantra / คำตั้งใจประจำตัว

**Premium expansion**
- Life stage interpretation by age band
- Deep work/money/love readings
- PDF or shareable card set

---

### Module B: Karma Mirror

**Goal:** Make the reading feel deep and memorable without using scary language.

**User-facing idea**

> กระจกกรรมไม่ใช่คำตัดสิน แต่คือรูปแบบปัญหาที่ชีวิตมักพาคุณกลับมาเรียนรู้ซ้ำ จนกว่าจะเห็นและเลือกต่างจากเดิม

**Signals**
- Weekday planet
- Element imbalance
- Thaksa shadow
- Lagna/rasi expression mismatch
- Age band pressure

**Output sections**
1. Pattern you repeat
2. Why it appears
3. What it tries to teach
4. What to do differently this month
5. Small ritual/action for 7 days

---

### Module C: Personal Auspicious Calendar

**Goal:** Replace generic good-day calendars with personal timing.

**Use cases**
- Start a project
- Negotiate / sign
- Sell or post content
- Ask for help from senior people
- Love/relationship conversation
- Rest and reset

**Result pattern**

```text
ดีที่สุด: วันพฤหัสบดี ช่วง 09:00–11:00
รองลงมา: วันอาทิตย์ ช่วง 13:00–15:00
ควรเลี่ยง: วันอังคารช่วงเย็น ถ้าต้องคุยเรื่องอารมณ์
เหตุผล: ดาวพฤหัสส่งเสริมการตัดสินใจระยะยาว และไม่ขัดกับธาตุประจำตัวของคุณ
```

### Module D: Couple Dharma Map

**Goal:** Make couple readings more Thai, more emotional, and more useful than a simple compatibility score.

**Pair types**

| Pair Type | Thai label | Meaning |
|---|---|---|
| Supportive Pair | คู่เกื้อหนุน | stable, practical, grows wealth/life together |
| Mirror Pair | คู่กระจกใจ | triggers each other but teaches growth |
| Fire Pair | คู่รักแรง | high passion, needs emotional discipline |
| Karma Lesson Pair | คู่บทเรียน | difficult but meaningful if both mature |
| Builder Pair | คู่สร้างฐาน | slow, stable, good for family/business |

**Outputs**
- Compatibility score remains, but is not the whole story.
- Add relationship pattern, communication advice, and one shared ritual/action.

## 4. UX and Visual Direction

### Visual identity

Recommended direction:
- Deep navy / cosmic indigo base
- Thai gold highlights
- Muted purple accents
- Minimal Thai motifs, not heavy temple graphics
- Subtle yantra/mandala geometry
- Premium card layout for sharing

### Do
- Use restrained Thai decorative patterns.
- Keep text readable on mobile.
- Make every result card screenshot-worthy.
- Use Thai + English labels sparingly for premium feel: `Thai Life Blueprint`, `Karma Mirror`, `Cosmic Brief`.

### Avoid
- Cheap neon fortune-teller visuals
- Overly scary karma language
- Too many emojis in final report sections
- Long wall-of-text without cards/tabs

## 5. Free vs Premium Strategy

### Free
- Basic Thai Life Blueprint
- Main planet, element, rasi/lagna
- One key strength
- One shadow pattern
- Lucky color/number card
- Short daily brief

### Premium 199 THB
- Full reading tabs
- Karma Mirror
- Love/career/money deep sections
- Age-band life map
- Personal auspicious calendar
- Couple Dharma Map details
- Exportable premium report/card set

**Important security note**

The current client-side PIN is not a production payment system. For public launch, premium access must move to a backend/payment-verification flow.
