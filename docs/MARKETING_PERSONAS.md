## 🥇 PRIMARY: ผู้หญิง 20-32 ปี urban (60-70%)

| เกณฑ์ | รายละเอียด |
|-------|------------|
| **อายุ** | 20-32 = TikTok native, active dating phase |
| **เพศ** | ผู้หญิง (testimonial = หญิง, copy ใช้ "ค่ะ/คะ", emoji ♡) |
| **ที่อยู่** | กรุงเทพฯ/เชียงใหม่/ภูเก็ต, smartphone-first |
| **รายได้** | 15-35k/mo — 199฿ = ค่าข้าว 1 มื้อ (impulse OK) |
| **ไลฟ์สไตล์** | Self-discovery, dating, แชร์ story IG/FB, อ่าน horoscope ประจำ |
| **Pain point** | "เขาคนนี้ใช่มั้ย?", "หนูควรเปลี่ยนงานมั้ย?", "ทำไมชีวิตเหมือนไม่เดิน" |
| **Trigger** | เลิกแฟน, เริ่มคบ, วันเกิด, เบื่อๆ, เพื่อนแชร์ |

### 💡 ทำไมกลุ่มนี้เหมาะที่สุด

1. **จ่าย 199฿/เดือน ไม่คิด** — เทียบเท่าค่าข้าว 1 มื้อ
2. **Share OG card ไป IG/FB story ได้** → virality ตามมา
3. **Compatibility check** = reason กลับมาใช้ซ้ำ (เช็กกับแฟน/คนที่ชอบ)
4. **TikTok "ดูดวงแม่น" content** ตรงกับ platform
5. **Visual-heavy product** (cosmic purple/gold) ตรง aesthetic ของกลุ่ม

## 🛠️ Marketing Strategy

### 📱 Content angles (TikTok)

| Hook | Format | Target |
|------|--------|--------|
| "ดูดวงฟรีก่อน แล้วคุยกัน" | Talking head + screen record | Freebie → premium |
| "เขาคนนี้ใช่มั้ย?" | Couple scenario + reveal | Compatibility |
| "ทำไมชีวิตไม่เดิน" | POV + fortune result | Life direction |
| "วันเกิดคุณบอกอะไร" | Quick hook + curiosity | Top of funnel |
| "แม่นมาก ขนลุก!" | Reaction + shareable card | UGC testimonial |
| "ดูดวงอาทิตย์นี้" | Daily fortune digest | Retention |
| "ฤกษ์แต่งงานปีนี้" | Specific date prompt | Decision-making |

### 📣 Channels

| Channel | Role | Format |
|---------|------|--------|
| **TikTok** | Primary (12:00-13:00) | Vertical 9:16, cosmic purple/gold |
| **LINE OA** | Retention | Daily fortune push 7:00 |
| **FB/IG Reels** | Backup | Share testimonials + OG card |
| **IG Story** | Share-driven | "ดูดวงฟรี ✨" + sticker |

### 💰 Conversion levers

| Action | Why | Expected impact |
|--------|-----|-----------------|
| **Bundle compatibility 299฿** (vs 398฿) | Increase AOV, reduce 2nd person friction | +30% couple conversion |
| **"ส่งดวงให้แฟน"** button | Gift mechanic, 1 user → 2 paid | +50% reach per paid user |
| **Anniversary reminder** (100/365 วัน) | Re-conversion at emotional moment | +20% retention |
| **Free daily fortune** | Top of funnel, sticky habit | +40% free → paid |

### 🔁 Retention hooks

| Hook | Frequency | Push |
|------|-----------|------|
| **Daily fortune** | ทุกเช้า 7:00 | LINE OA / push notif |
| **Compatibility** | milestone | Email "วันนี้ครบ 1 ปี 🎉" |
| **Weekly premium** | weekly | "ดวงอาทิตย์นี้เปลี่ยน!" (Variable reward) |

### ⚠️ Risks & Mitigation

| Risk | Mitigation |
|------|------------|
| Copy ฟังดูแม่น → ถ้าผิด = backlash | ใส่ disclaimer "ดวงเป็นแนวทาง ไม่ใช่คำทำนาย" |
| TikTok algorithm เปลี่ยน | ไม่พึ่ง channel เดียว — เตรียม FB Reels / IG Reels |
| Premium tier ขาดต่อ (199 → ???) | ควรมี tier 499/1299 สำหรับ deeper reading |
| ผู้ชายเป็น secondary จริงๆ | ถ้าจะเจาะกลุ่มผู้ชาย ต้อง copy/visual ใหม่หมด |

## 🎯 Quick wins (เริ่มได้ทันที)

1. **LINE OA daily push** — คนกลับมาทุกวัน (free → premium)
2. **Bundle compatibility 299฿** — LTV สูงขึ้น 2 เท่า
3. **TikTok "ดูดวงฟรี" content** — top funnel (3 hooks/สัปดาห์)
4. **Retargeting FB/IG** คนที่เข้าแต่ไม่จ่าย
5. **"ส่งดวงให้แฟน" gift button** — viral + paid
