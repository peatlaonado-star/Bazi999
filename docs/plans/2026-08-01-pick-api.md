# Pick-a-Card API (quota + streak จริง) Implementation Plan

> **วันที่:** 2026-08-01
> **เป้าหมาย:** แทนที่ quota/streak/history จำลอง (hardcode ใน pick-a-card.js) ด้วย API จริง `/v1/pick/*` บน Cloudflare Pages Functions + KV

**Goal:** ผู้ใช้เปิดไพ่ได้ 1 ครั้ง/วัน (ฟรี) นับ streak วันติดต่อ และเก็บประวัติ — ข้อมูลอยู่บน server ไม่หายเมื่อโหลดหน้าใหม่

**Architecture:** CF Pages Functions (`functions/_lib/pick.js`) เก็บ state ต่อผู้ใช้ใน KV namespace `STARVIA_KV` (key `pick:{fingerprint}`) ระบุผู้ใช้ด้วย fingerprint (SHA-256 ของ UA+IP — pattern เดียวกับ `streak.js`) Frontend เรียก GET/POST `/v1/pick/*`

**Tech Stack:** Cloudflare Pages Functions, Workers KV, vanilla JS frontend, vitest

---

## Business Rules

- **Quota:** 1 ครั้ง/วัน (รีเซ็ตตามวันไทย UTC+7 เที่ยงคืน) — ตรงกับ design เดิม `quotaLeft: 1`
- **Streak:** เปิดไพ่วันนี้ติดต่อจากเมื่อวาน → +1 / วันเดียวกัน → คงเดิม / ขาด >1 วัน → reset = 1
- **History:** เก็บ 10 ครั้งล่าสุด (ใหม่สุดก่อน)
- **วันอ้างอิง:** คำนวณแบบ Bangkok timezone (UTC+7) — `todayKey()`

## Tasks

### Task 1: เขียน tests (RED)
- `tests/pick.test.js`: ทดสอบ pure functions `refreshDaily()`, `applyDraw()` + HTTP handlers (state/draw)
- คาดว่า FAIL (module ยังไม่มี)

### Task 2: สร้าง `functions/_lib/pick.js` (GREEN)
- `todayKey()` — YYYY-MM-DD ตาม UTC+7
- `refreshDaily(prev, today)` — รีเซ็ต quota ถ้าข้ามวัน (pure)
- `applyDraw(prev, today, entry)` — หัก quota 1, อัปเดต streak, push history (pure, cap 10)
- `getPickState(context)` — GET: อ่าน KV → refreshDaily → เขียนถ้าเปลี่ยน → คืน state
- `drawPick(context)` — POST: อ่าน KV → refreshDaily → quota<=0 → 429 → else applyDraw → เขียน → คืน state ใหม่
- `createFingerprint(request)` — copy จาก streak.js (SHA-256 UA+IP → 16 hex)
- KV key: `pick:{fingerprint}`

### Task 3: เพิ่ม route ใน `[[path]].js`
```js
if (segments[0] === 'pick') {
  if (segments[1] === 'state' && request.method === 'GET') return getPickState(context);
  if (segments[1] === 'draw' && request.method === 'POST') return drawPick(context);
}
```

### Task 4: แก้ frontend `pick-a-card.js`
- `boot()` → fetch `/v1/pick/state` → เติม state (quota/streak/history จริง)
- `pickCard()` → POST `/v1/pick/draw` { topic, slug, name, emoji } → อัปเดต state จาก response
- API fail → fallback ค่าเริ่มต้น (ไม่พัง, แสดง error เบาๆ)

## Response shapes

```
GET /v1/pick/state → 200 { success, quotaLeft, streak, history, today }
POST /v1/pick/draw { topic, slug, name, emoji }
  → 200 { success, quotaLeft, streak, history, today }
  → 429 { success:false, error:'QUOTA_EXCEEDED', message:'วันนี้เปิดไพ่ครบ 1 ครั้งแล้ว พรุ่งนี้มาใหม่นะคะ ✨' }
  → 400 { success:false, error:'MISSING_CARD' } (ไม่มี slug)
  → 500 { success:false, error:'KV_NOT_BOUND' } (env ไม่มี KV)
```
